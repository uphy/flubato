# flubato

Guitar Pro のタブ譜を読み込んで、実物のギターで弾く練習アプリ。マイクで音を聞き取る。ブラウザで動く。

**▶ https://flubato.uphy.dev**

ソロギター（指弾き）向け。キーボードや画面のタップではなく、ギターを弾いて進める。
名前は flub（しくじる）と rubato（ルバート）から。つっかえても、溜めても走っても、譜面のほうが合わせる。

## モード

| モード | 中身 |
|---|---|
| 練習（既定） | 弾くと譜面がついてくる。止まったら待ち、弾き直したら戻ったことを察して追う。終わるとつっかえた小節が出る。「再生」で譜面の音を鳴らして聞ける（聞いている間は弾いた音を聞き取らない。ヘッドホンで） |
| 音ゲー | 音符が流れてきて判定ラインを通る。1音ずつ当たり・外れとタイミングを出す |
| 振り返り | 終わったあと、苦手な小節の一覧と、直前に通して弾いた回の録音を行き来する |

練習モードで通す → つっかえた小節が分かる → その小節を音ゲーモードで遅めにくり返す → 最後に音ゲーモードで通す、という使い方を想定している。

### 音ゲーモードでできること

- 小節の範囲を決めてくり返す。速さは 40〜120%
- テンポを合わせる（既定でオン）。曲の時計を弾く人の溜めや走りに寄せ、弾くはずの和音を過ぎても少し待つ
- 判定ラインが拍ごとに光る（小節の頭は黄色）。音のメトロノームも鳴らせる
- タイミング合わせ。1弦の開放を12回弾いて、マイクの遅れを測る
- 終わると小節ごとの出来が出て、押すとその小節のくり返し練習になる

### 振り返りで分かること

箇所を選ぶと、タブ譜の上に何が悪かったかが出て、その小節を録音で聞ける。

- 練習モード: 止まった・間が空いた・急いだ・戻った・飛ばした・聞き取れなかった音
- 音ゲーモード: 早い・遅い・外した音

## 使い方

1. 「曲を開く」で Guitar Pro（.gp / .gp5 / .gpx など 3〜8）か MusicXML を読み込む。最初は練習用の短い曲（Romance の簡易アレンジ）が入っている
2. 変則チューニングやカポの曲は、曲名の下に `DADGAD · カポ 6` のように出る。押すとチューナーが開き、曲のチューニングの弦ごとに合わせられる（何半音回すかも出る）。カポは合わせてから付ける
3. 「弾きはじめる」（音ゲーモードでは「はじめる」）を押すと、ブラウザがマイクの許可を聞いてくる
4. ギターをマイクの近くで弾く

スピーカーで音のメトロノームを鳴らすと、その音をマイクが拾って判定が乱れることがある。鳴らすならヘッドホンで。

## 動く環境

- PC・タブレットの Chrome / Edge / Safari / Firefox の新しめの版
- マイクは https か localhost でしか使えない。宅内の IP アドレス（http）で開くとマイクが使えない

## 扱う情報

マイクの音と録音は端末の中だけで処理し、どこにも送らない。設定（マイクの遅れなど）はブラウザの localStorage に保存する。
「調査用に保存」を押したときだけ、録音と判定の記録を1つの wav ファイルとして端末にダウンロードする。
